# 0011. シーンを「家」と「散歩」の2つとし、タイトル画面を設けない

- Status: Accepted
- Date: 2026-09-25

## Context

世話のうち散歩は、家の中だけでは表現しにくい。散歩の場所の決め方によって、シーンの数・
シーン管理の要否・背景アセットの量が変わる。

また、ポートフォリオとして見る人は5〜10分程度しか遊ばない前提である
（[0008](0008-time-progression-hybrid.md)）ため、起動から遊べるまでの手順は短いほうがよい。

## Decision

シーンを次の2つとする。

- `scene_home`: 家の中。ごはん・なでる・しつけ・遊ぶを行う
- `scene_walk`: 屋外の広場。散歩を行う

起動からの流れは次のとおりとし、タイトル画面は設けない。

```
起動
 ├─ セーブなし → 子犬を迎える場面で名前を入力 → scene_home
 └─ セーブあり → scene_home（おかえりの表示と、閉じていた間の経過を表示）
```

セーブデータは犬1匹分・1スロットのみとする。

## Consequences

- 散歩中の3D表現（屋外を歩く犬）を見せられる
- シーンの切り替えが必要になり、`app` にシーン管理を自作する
  （[0003](0003-no-game-engine-cpp-with-small-libraries.md) の自作範囲）
- 背景アセットが家と屋外の2シーン分必要になる
- 見る人は起動直後から遊べる。初回の名前入力で愛着を持つきっかけを作れる
- スロットが1つのため、最初からやり直す手段はセーブファイルの削除になる。
  必要になった時点で、デバッグUIなどにリセット操作を追加する

## Alternatives considered

- **家と庭を1シーンにし、散歩は庭のコースを歩く**: シーン切り替えが不要で工数は少ないが、
  散歩らしさが弱い
- **散歩を演出で省略（玄関から出てフェードアウトし、帰宅する）**: 工数は最小だが、
  散歩中の犬を3Dで見せられない
- **タイトル画面（はじめる／つづきから／終了）を設ける**: ゲームらしさは出るが、
  シーンが1つ増え、既存セーブを上書きするかの確認も必要になる
- **名前を固定にする**: 最も手軽だが、愛着を持つきっかけが1つ減る
