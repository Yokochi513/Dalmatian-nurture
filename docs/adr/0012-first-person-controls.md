# 0012. 一人称視点で歩き回り、視線の先の対象へ E キーで世話をする

- Status: Accepted
- Date: 2026-09-25

## Context

[0011](0011-scenes-home-and-walk.md) で家と散歩の2シーンを設けた。散歩ではプレイヤーが
飼い主を自由に動かし、犬がついてくる形にしたい。視点と操作の方式によって、
飼い主のモデルとアニメーションの要否、シーンごとの操作の違い、カメラ制御の量が変わる。

## Decision

- 家・散歩とも **一人称視点** とし、カメラを飼い主の目とする。飼い主のモデルは表示しない
- 移動は **WASD、視点はマウス** で操作する。操作は両シーンで共通とする
- 世話は、犬や物（餌皿など）を画面中央の照準で捉えて **E キー** を押すと、その対象に
  できる世話がメニューで表示され、選んで実行する。選択肢が1つだけの場合はメニューを
  出さずにそのまま実行する

```
[犬を捉える] → E
┌─ ポチ ───┐
│ なでる   │
│ しつける │
│ 遊ぶ     │
└──────────┘
[餌皿を捉える] → E → ごはんを入れる
```

## Consequences

- スキンメッシュは犬のみでよく、人のモデルとアニメーションが不要になる
- 犬が画面の主役になり、仕草を近くから見せられる
- 移動・当たり判定・カメラを両シーンで共通化できる
- 飼い主の移動と、視線の先の対象の判定に当たり判定が必要になる
  （[0014](0014-physics-jolt.md)）
- マウスを視点操作に使うため、メニュー表示中はカーソルを表示して視点操作を止めるなど、
  入力モードの切り替えが必要になる
- 一人称では犬の全身が見えにくい場面がある。必要になった時点で、カメラを引く操作などを
  検討する

## Alternatives considered

- **三人称で飼い主を表示する**: 見栄えはよいが、人のモデル・歩行アニメーション・
  壁にめり込まないカメラ制御が追加で必要になる
- **家は見下ろしの固定カメラでクリック操作、散歩だけ一人称**: 家で犬の全身を見せやすいが、
  操作とカメラが2種類になる
- **散歩は決まった道を自動で歩く／眺めるだけ**: 当たり判定がほぼ不要で簡単だが、
  散歩を別シーンにした意味が薄れる
- **道具を持ち替えてクリックで使う**: ボールを投げるなど遊びの幅は広いが、手に持った道具の
  表示と投げた物の挙動が必要になる
- **画面に世話のボタンを常に並べる**: 分かりやすいが、一人称で歩き回る意味が薄れ、
  マウスによる視点操作とも衝突する
