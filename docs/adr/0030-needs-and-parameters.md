# 0030. 欲求は世話に対応する5つとし、機嫌は欲求から計算し、なつき度は積み上げる

- Status: Accepted
- Date: 2026-09-25

## Context

[0008](0008-time-progression-hybrid.md) には空腹・眠気・機嫌・なつき度が登場するが、欲求の一覧は
決まっていない。世話はごはん・散歩・なでる・しつけ・遊ぶの5つである（README）。
世話で満たせない欲求があると、プレイヤーにはそれを満たす手段がなくなる。

## Decision

犬の状態として次を持つ。

```
欲求（時間で増える）
  空腹   ← ごはん
  運動   ← 散歩（[0018] により散歩中の時間で満たされる）
  退屈   ← 遊ぶ
  寂しさ ← なでる
  眠気   ← 犬が自分で寝る
機嫌    ：5つの欲求から計算する（保存しない）
なつき度：世話で上がり、放置で少し下がる
```

しつけは欲求を満たすのではなく、芸の習得に使う（[0035](0035-trick-learning.md)）。

## Consequences

- すべての欲求を、世話か犬の自律行動のどちらかで満たせる
- 世話ごとに満たす欲求が異なり、どの世話をするかに意味が生まれる
- 機嫌は保存せず毎回計算するため、欲求と機嫌の食い違いが起きない
- 放置による悪化は機嫌となつき度の低下にとどまり、[0008](0008-time-progression-hybrid.md) の
  「放置で犬が死ぬ・いなくなることはない」を満たす
- 欲求が5つあるため、変化率や上限などのバランス調整の項目が多くなる

## Alternatives considered

- **空腹・眠気・機嫌の3つに絞る**: 調整は楽だが、散歩・遊ぶ・なでるがすべて機嫌を上げるだけに
  なり、世話の違いが数値に表れない
- **トイレ・清潔も加える**: 本物の犬らしさは増すが、トイレの片付け・お風呂という世話が増え、
  アニメーションと演出も増える
