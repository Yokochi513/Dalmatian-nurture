# 0008. 時間の進み方は「時刻は現実時間、成長は世話の積み重ね」のハイブリッドとする

- Status: Accepted
- Date: 2026-09-25

## Context

本作は「本物の犬を育てるように」世話をすべてこなす育成ゲームであり、エンディングは設けない。
一方でポートフォリオとして公開するため、見る人が遊ぶのは多くの場合5〜10分程度である。
リアル感と、短時間で成長を体験できることの両立が求められる。

また、育成ロジック（`dalmatian_core`）は描画に依存しないテスト対象として分離する方針である
（[0005](0005-build-system-cmake-msvc-cpp20.md)）。

## Decision

時間の扱いを次の2つの軸に分ける。

- **時刻の軸（現実時間と1:1で同期）**: 昼夜、空腹・眠気などの欲求は現実時間で進む。
  アプリを閉じている間も進む。
- **成長の軸（世話の積み重ね）**: 子犬→成犬の成長と芸の習得は、世話・しつけ・練習を
  行った実績によって進む。経過時間だけでは成長しない。

閉じている間の変化には次の制約を設ける。

- 欲求の変化量には上限を設け、長期間の放置でも一定以上は悪化しない
- 放置によって犬が死ぬ・いなくなることはない（悪化は機嫌やなつき度の低下にとどめる）

具体的な数値（上限値、成長に必要な世話の量など）はゲームバランス調整の中で決める。

## Consequences

- 現実時間と同期した昼夜・欲求によってリアル感と愛着を出しつつ、見る人も世話を
  重ねることで短時間で成長を体験できる
- 放置しても成長が遅れるだけで、罰になりにくい
- 時間の軸が2つになるため、バランス設計の難度が上がる。特に「短時間に世話を
  繰り返せば一気に成犬になる」ことを防ぐ仕組み（1日あたりの効果の上限、
  クールダウンなど）が必要になる
- 育成ロジックはOSの時計を直接読まず、外部から時計を注入される設計とする。
  これにより時間経過をテストで再現でき、ImGuiのデバッグUIから早送りも行える
- セーブデータに最終終了時刻を保存し、再開時に経過時間を計算する必要がある
- PCの時計を変更すると時刻の軸を操作できる。成長は時間では進まないため影響は
  欲求と昼夜に限られ、対策は行わない

## Alternatives considered

- **現実時間と1:1で完全同期（成長も時間で進む）**: リアル感は最大だが、成犬まで
  数か月かかり、ポートフォリオとして成長を見せられない
- **現実時間と同期した倍速進行**: 閉じている間の時間経過は残せるが、昼夜が現実と
  ずれ、数時間の放置で何日分も進んで世話が追いつかない
- **起動中のみ進む**: 放置の罰や時計操作の問題はないが、「いない間も犬が暮らしている」
  感覚が失われ、コンセプトから離れる
- **ゲーム内日数を行動で進める（ターン制）**: デモとテストは容易だが、生き物らしさが
  最も弱く、3Dのアイドルアニメーションを見せる意味が薄れる
- **モード選択式**: 両方の方向性を満たせるが、2モード分のバランス調整とテストが必要で、
  方針の決定を先送りすることになる
