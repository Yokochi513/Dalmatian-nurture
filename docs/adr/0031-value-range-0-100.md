# 0031. 欲求となつき度は小数の0〜100で表し、欲求は大きいほど強く欲しがっている

- Status: Accepted
- Date: 2026-09-25

## Context

[0021](0021-fixed-one-second-tick.md) により `core` は1秒刻みで進むため、欲求は1秒ごとに
ごくわずかに変わる（空腹が8時間で最大になるなら、1秒あたり約0.0035）。
値の型・範囲・向きを決める必要がある。

## Decision

- 欲求（[0030](0030-needs-and-parameters.md)）となつき度は **小数（double）の0〜100** で表す
- 欲求は **大きいほど強く欲しがっている**（0 = 満たされている、100 = 限界）
- UIのゲージは「満足度 = 100 − 欲求」として表示してよい

```
"hunger": 42.37    // 0 = 満腹、100 = 限界
"affection": 63.0  // なつき度
```

## Consequences

- 1秒刻みのわずかな変化を表せる
- セーブ（JSON）やデバッグUIで値を見たときに、感覚をつかみやすい
- 小数の誤差があるため、しきい値の判定や、1秒刻みと不在の計算の一致の確認
  （[0022](0022-offline-catch-up-needs-only.md)）では誤差を許容して比べる
- 範囲外の値は0〜100に切り詰める。セーブの読み込み時に範囲外なら「読めない」として扱う
  （[0027](0027-save-atomic-write-and-backup.md)）

## Alternatives considered

- **小数の0〜1**: 数式には扱いやすいが、セーブやデバッグUIで値を見たときに感覚をつかみにくい
- **0〜1,000,000の整数**: 小数の誤差がなく、実行環境によらず完全に同じ結果になるが、
  変化率の設定や値の確認が分かりにくくなる
