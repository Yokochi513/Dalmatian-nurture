# 0027. セーブは一時ファイル経由で書き込み、1世代のバックアップを残す

- Status: Accepted
- Date: 2026-09-25

## Context

[0026](0026-save-timing.md) によりセーブの回数が増え、書き込みの途中で強制終了する可能性も
増えた。[0011](0011-scenes-home-and-walk.md) によりセーブは1スロットだけであり、ファイルが
壊れると犬を失う。セーブはJSONで手で編集できる（[0006](0006-dependency-libraries.md)）ため、
編集の誤りで壊れることもある。

## Decision

保存と読み込みを次の手順で行う。

```
保存：save.json.tmp に書き終える
      save.json     → save.json.bak（直前の1世代を残す）
      save.json.tmp → save.json
読込：save.json を読む → 読めなければ save.json.bak
      → どちらも読めなければ、壊れたファイルを *.broken に退避し、
        そのことをプレイヤーに伝えてから新しく始める
```

## Consequences

- 書き込みの途中で落ちても、本番のファイルが中途半端な内容になることはない
- 手で編集して壊した場合も、直前の状態に戻れる
- 壊れたファイルは消さずに残るため、原因を調べたり手で直したりできる
- 「読めない」には、JSONとして解釈できない場合だけでなく、必要な項目が欠けている場合や
  値が範囲外の場合も含める。この判定は `core` の `save` で行う
- ファイルの書き込みと入れ替えは `core` の外で行う（[0009](0009-module-structure.md) で
  `core` の `save` はJSONとの相互変換を担う）

## Alternatives considered

- **一時ファイル経由のみ（バックアップなし）**: 保存の途中で落ちても壊れないが、手で編集して
  壊した場合などは元に戻せない
- **直接上書き**: 最も単純だが、保存の途中で落ちるとファイルが壊れ、犬を失う
