# 0021. core は1秒の固定刻みで時間を進める

- Status: Accepted
- Date: 2026-09-25

## Context

[0008](0008-time-progression-hybrid.md) により、欲求や昼夜は現実時間と同期して進み、
`core` には外から時計を注入する。`core` を1回進めるごとに時間をどれだけ進めるか
（刻み）を決める必要がある。

## Decision

- `app` は毎フレーム、注入された時計の現在時刻を `core` に渡す
- `core` は前回からの経過を **1秒の固定刻み** で処理し、1秒に満たない端数は次回へ持ち越す

```
app : sim.step(clock.now())   // 毎フレーム
core: 前回から 2.7 秒 → 1秒刻みを2回処理
      端数 0.7 秒は次回へ持ち越し
```

## Consequences

- フレームレートによって結果が変わらず、テストで同じ結果を再現できる
- 「欲求がしきい値を超えた瞬間」などの判定が実行環境によってずれない
- 欲求・クールダウン・散歩の積み上げ（[0018](0018-walk-state-in-core.md)）は秒単位の精度になる。
  育成ゲームの変化としては十分である
- ゲージの表示はフレームごとには変わらず1秒ごとに変わる。滑らかに見せたい場合は
  UI側で表示値を補間する

## Alternatives considered

- **フレームごとの経過時間で進める**: 最も単純だが、小数の誤差のたまり方がフレームレートで
  変わり、しきい値の判定が実行環境によってずれる
- **1分の固定刻みで進める**: 長い不在でも計算回数が少ないが、クールダウンの残り時間や
  散歩の積み上げが1分単位になり、起動中の変化が粗く見える
