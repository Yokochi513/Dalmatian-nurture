# 0036. 成長は世話でたまる成長ポイントで進め、最初の成長は初回のプレイ中に届くようにする

- Status: Accepted
- Date: 2026-09-25

## Context

[0008](0008-time-progression-hybrid.md) により、成長は世話の積み重ねで進み、見る人も短時間で
成長を体験できるようにしたい。一方で、短時間に世話を繰り返して一気に成犬になることは防ぐ。
成長を何で進め、どのくらいのペースを目標にするかを決める必要がある。

## Decision

- 受け付けた世話ごとに **成長ポイント** がたまり、しきい値に達すると次の段階
  （[0033](0033-growth-stages-bone-scale.md)）になる。成長したときは出来事 Grew を返す
- 世話のクールダウンと1日の上限（[0008](0008-time-progression-hybrid.md)、[0023](0023-day-boundary-local-midnight.md)）
  により、1日にたまる成長ポイントにも上限がかかる
- ペースの目標：
  - 子犬 → 若犬：**初回のプレイの10分以内**
  - 若犬 → 成犬：**数日**

具体的な数値は、この目標に合わせてバランス調整の中で決める。

## Consequences

- ポートフォリオを見る人も、最初のプレイで成長を1回体験できる
- 成犬になるまでは数日通う必要があり、育てる実感が残る
- 子犬の間は1日の上限に早く届かないよう、上限と成長ポイントの配分を段階ごとに調整する必要がある
- 成犬の姿はデバッグUIの早送り（[0025](0025-debug-time-controls.md)）や動画で見せることになる

## Alternatives considered

- **成長ポイントに加えて、その段階の芸をすべて覚えることを条件にする**: しつけの目的ははっきり
  するが、しつけをしないと成長しない
- **どの段階も数日かける**: 育てる実感は強いが、見る人が成長を体験できない
