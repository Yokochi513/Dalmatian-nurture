# 0023. 「1日」の区切りは現地時刻の0時とする

- Status: Accepted
- Date: 2026-09-25

## Context

[0008](0008-time-progression-hybrid.md) により、世話には1日あたりの上限がある。
[0017](0017-care-availability-with-reason.md) でメニューに「今日はもう満足」のような理由を表示する。
上限が戻る「1日」の区切りを決める必要がある。

## Decision

「1日」の区切りは **PCの現地時刻の0時** とする。区切りの時刻は1か所の定数として持つ。

## Consequences

- カレンダーの日付と一致し、実装・テスト・説明が最も単純になる
- 0時をまたいで遊ぶと、23:50に上限まで世話をした直後の0:00に再び世話ができる。
  得られるのは1日分の上限にとどまり、主な遊び手（5〜10分遊ぶポートフォリオの閲覧者）が
  0時をまたぐ場面は少ないため、許容する
- `core` が現地の日付を判定できるよう、時計のインターフェースは現地時刻（またはタイム
  ゾーンのずれ）を提供する必要がある
- 問題になった場合は、定数を変えるだけで午前4時などに変更できる

## Alternatives considered

- **現地時刻の午前4時**: 寝るまでを「今日」とする感覚に合い、深夜0時の抜け道も防げるため、
  多くのゲームが採用している。本作の遊ばれ方では効果が小さく、日付とずれる分だけ説明が増える
- **直近24時間の回数で数える**: 時刻やタイムゾーンに左右されないが、世話ごとに回復する時刻が
  ばらばらになり、「今日は」という表現が使えない
