# 0018. 散歩中は core が散歩の状態を持ち、効果を散歩の時間に応じて積み上げる

- Status: Accepted
- Date: 2026-09-25

## Context

[0011](0011-scenes-home-and-walk.md) と [0012](0012-first-person-controls.md) により、
散歩は屋外のシーンでプレイヤーが飼い主を自由に動かし、犬がついてくる形になった。
散歩はほかの世話と違い何分も続くため、[0016](0016-care-effect-on-accept.md) の
「効果は受け付けた時点で確定する」をそのまま当てはめると、すぐ帰っても長く歩いても
効果が同じになる。

## Decision

- `app` が散歩の開始を伝えると、`core` は **散歩中の状態** になる
- 散歩中も犬の行動意図は `core` が決める（Follow：飼い主についていく、Sniff：匂いを嗅ぐ など）
- 散歩の効果（運動の欲求の充足など）は、**散歩中の時間に応じて上限付きで積み上げる**
- 家に戻ったら `app` が散歩の終了を伝える
- 飼い主を追う移動そのものは `app` が `physics` を使って行う

```
app → core : 散歩開始
core       : 散歩中、意図 = Follow / Sniff / ...
core       : 散歩中の時間に応じて効果を積み上げ（上限あり）
app        : 飼い主を追う移動は physics で行う
app → core : 散歩終了
```

## Consequences

- 散歩の長さが効果に反映される
- 散歩中も「犬の気持ちは `core` が決める」という分担が崩れない
- 散歩中の時間の積み上げはテスト用の時計で再現できる
- 散歩中にアプリが終了した場合の扱い（次回起動時に家から始め、散歩は終了扱いにする など）
  を決める必要がある

## Alternatives considered

- **効果は開始時に確定し、散歩中の犬は `app` が動かす**: 最も単純だが、散歩の長さが
  効果に影響しない
- **犬は `app` が動かし、終了時に時間や距離を `core` に渡す**: 距離も効果に使えるが、
  散歩中だけ犬の気持ちを `core` が決めない例外が生まれる
