# 0029. セーブには犬の状態だけを保存し、シーンと位置は保存しない

- Status: Accepted
- Date: 2026-09-25

## Context

[0018](0018-walk-state-in-core.md) で、散歩中にアプリを終了した場合の扱いが未決になっていた。
これは、シーンや飼い主・犬の位置をセーブに含めるかどうかと合わせて決める必要がある。

## Decision

- セーブに含めるのは **犬の状態**（`core` の状態）、最終終了時刻、形式の番号
  （[0028](0028-save-format-version.md)）だけとし、**シーンと飼い主・犬の位置は保存しない**
- 散歩中に終了した場合は、その時点で散歩が終わったものとして扱い、それまでに積み上げた効果は残す
- 次回の起動時は、必ず家（`scene_home`）の決まった場所から始める

```
セーブに含める：犬の状態、最終終了時刻、形式の番号
含めない    　：シーン、飼い主と犬の位置
散歩中に終了 → そこで散歩終了、効果は残る
次回        → 家の決まった場所から
```

## Consequences

- セーブの内容が `core` の状態だけになり、`app` の状態の保存と復元が不要になる
- 散歩の効果は時間に応じて積み上がり、1分ごとにセーブされる（[0026](0026-save-timing.md)）ため、
  散歩の途中で終了しても効果はほぼ失われない
- 散歩中かどうかは `core` の状態にあるため、読み込み時に散歩中であれば散歩を終了させる。
  起動時の「おかえり」の表示（[0011](0011-scenes-home-and-walk.md)）と自然につながる
- 途中のシーンや位置からは再開できない

## Alternatives considered

- **シーンと位置も保存して再開する**: 続きから遊べるが、`app` の状態もセーブに含まれ、
  閉じていた間も散歩中として扱うかどうかを決める必要がある
