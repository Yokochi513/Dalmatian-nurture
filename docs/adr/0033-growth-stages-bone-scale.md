# 0033. 成長段階は3つとし、見た目は1体のモデルのボーンの大きさで変える

- Status: Accepted
- Date: 2026-09-25

## Context

README で「子犬から成犬へ成長する」と定めたが、段階の数と見た目の変え方は決まっていない。
見た目の変え方によって、必要な3Dモデルとアニメーションの数が変わる。

## Decision

- 成長段階は **子犬 → 若犬 → 成犬** の3つとする
- 見た目は **成犬のモデル1体** を使い、全体の大きさと一部のボーンの比率を段階ごとに変える
  （例：子犬は全体 ×0.5、頭 ×1.3、足 ×0.8）
- アニメーションクリップは全段階で共通とする

## Consequences

- モデルとアニメーションが1セットで済む
- ボーンごとに大きさを上書きする処理が `anim` に必要になる。スケルタルアニメーションを自作する
  本作の見せ場の1つになる（[0003](0003-no-game-engine-cpp-with-small-libraries.md)）
- 比率を変えると足が地面から浮く・めり込むことがあるため、段階ごとに高さの補正が必要になる
- 子犬らしい丸みなど、比率だけでは表せない違いは表現できない
- 成長段階は `core` の状態であり、段階ごとの比率は `app` が持つ

## Alternatives considered

- **2段階でモデル2体**: 見た目の差は大きいが、モデルとアニメーションが2セット必要になる
- **3段階でモデル3体**: 成長の実感は最も強いが、アセットの工数が3倍になる
