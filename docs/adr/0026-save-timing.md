# 0026. セーブは1分ごと・世話の直後・シーンの切り替え時・終了時に行う

- Status: Accepted
- Date: 2026-09-25

## Context

[0008](0008-time-progression-hybrid.md) により、セーブには最終終了時刻を保存し、起動時に
経過時間を計算する。セーブが終了時だけだと、強制終了したときにその回の世話がすべて失われ、
経過時間も前回の終了時刻から計算されてしまう。

## Decision

次のときにセーブする。

- 1分ごと（自動）
- 世話を受け付けた直後（[0016](0016-care-effect-on-accept.md) により効果が確定した時点）
- シーンの切り替え時
- 終了時

セーブに保存する「最終終了時刻」は、**最後にセーブした時刻** として扱う。

## Consequences

- 強制終了しても、失うのは最大1分間の欲求の変化だけで、世話の実績は失われない
- 強制終了した場合も、最後にセーブした時刻から不在の計算（[0022](0022-offline-catch-up-needs-only.md)）が
  正しく行われる
- セーブの回数が増えるため、書き込みの途中で落ちてもファイルが壊れない仕組みが必要になる
  （[0027](0027-save-atomic-write-and-backup.md)）
- セーブはメインループの中で行うため、1回の保存が数ミリ秒で終わる大きさに保つ

## Alternatives considered

- **終了時だけ**: 最も単純だが、強制終了するとその回の進行がすべて失われる
- **世話の直後と終了時**: 世話の実績は失われないが、世話をせずに眺めていた時間が強制終了で
  失われ、最終終了時刻が古くなる
