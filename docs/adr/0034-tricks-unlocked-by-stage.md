# 0034. 芸は5つとし、成長段階に応じて練習できるようにする

- Status: Accepted
- Date: 2026-09-25

## Context

README で「芸を覚えさせることができる」と定めたが、芸の一覧は決まっていない。
芸1つにつきアニメーションクリップが1本必要になる。

## Decision

芸を次の5つとし、成長段階（[0033](0033-growth-stages-bone-scale.md)）に達すると練習できるようになる。

| 段階 | 芸 |
|---|---|
| 子犬 | おすわり、お手 |
| 若犬 | ふせ、まて |
| 成犬 | ぐるぐる回る |

## Consequences

- 成長すると新しい芸を練習できるようになり、成長の実感につながる
- 芸のクリップは5本で済む
- 成犬になって芸をすべて覚えると、新しい目標がなくなる。エンディングがない
  （README）ため、覚えた後の遊び方は必要になった時点で検討する

## Alternatives considered

- **3つで最初からすべて練習できる**: アセットは最小だが、成犬で覚えるものがなく、すぐに覚え終わる
- **8つ（おかわり・ハイタッチ・ばーんを追加）**: 遊びの幅は広いが、クリップが8本になる
