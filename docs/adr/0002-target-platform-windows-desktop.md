# 0002. 対象プラットフォームをWindowsデスクトップに限定する

- Status: Accepted
- Date: 2026-09-25

## Context

ダルメシアンの育成3Dゲームを、ポートフォリオとして公開することを目的とする。
候補はブラウザ（Web）、Windows PC、スマートフォンの3つだった。

## Decision

対象プラットフォームを **Windows デスクトップ（実行ファイル配布）のみ** とする。

## Consequences

- 3D表現の自由度と性能で制約を受けない
- Windows固有のAPIやOpenGL 4.6を前提にできる（[0004](0004-graphics-api-opengl-46.md)）
- クロスプラットフォーム対応を将来行う場合、描画層とプラットフォーム層の書き換えが必要になる。
  これを見越してディレクトリ構成で層を分離する（[0005](0005-build-system-cmake-msvc-cpp20.md)）
- 「URLを開くだけで遊べる」手軽さは得られないため、公開時は動画やスクリーンショットの
  用意が必須になる

## Alternatives considered

- **ブラウザ（Web）**: 共有は最も容易だが、ロード時間と3D表現に制約があり、
  C++自作路線（[0003](0003-no-game-engine-cpp-with-small-libraries.md)）とはWasm経由で
  相性が悪い
- **スマートフォン**: 育成ゲームとの相性は良いが、ストア審査・実機テストの
  コストが目的に対して過大
