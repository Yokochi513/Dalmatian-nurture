# 0025. デバッグUIの早送りは、倍速の時計と「不在の再現」ボタンで行う

- Status: Accepted
- Date: 2026-09-25

## Context

[0008](0008-time-progression-hybrid.md) で、ImGuiのデバッグUIから早送りできるようにすると
決めた。起動中の時間の流れ（[0021](0021-fixed-one-second-tick.md)）と、閉じていた間の
計算（[0022](0022-offline-catch-up-needs-only.md)）の両方を、実際に待たずに確かめたい。

## Decision

`app` に **デバッグ用の時計**（実時間 × 倍率 + オフセット）を置き、`core` に注入する。
デバッグUIには次の2つを設ける。

- **時間の進み**: ×1 / ×10 / ×60 / ×3600 を切り替える。起動中と同じ1秒刻みで進む
- **不在の再現**: 1時間 / 8時間 / 24時間 / 7日 を選ぶと、その時間だけ閉じていたものとして
  不在専用の計算を行い、「おかえり」の表示まで確かめられる

`core` はどちらの場合も、本物の時計と区別しない。

## Consequences

- 昼夜・欲求・犬の行動の変化の過程と、不在からの復帰の両方を、待たずに確かめられる
- `core` にデバッグ専用のコードが入らない
- デバッグ用の時計で進めた状態でセーブすると、最終終了時刻が未来になる。次回に本物の
  時計で起動すると時計が戻ったことになるため、[0022](0022-offline-catch-up-needs-only.md) の
  とおり経過時間を0として扱う
- 公開する実行ファイルでデバッグUIを使えるようにするかは別途決める

## Alternatives considered

- **倍速の時計だけ**: 実装は最小だが、閉じていた間の計算を確かめるには実際に閉じて待つか、
  セーブファイルを書き換える必要がある
- **時刻を直接跳ばすだけ**: 昼夜は確かめやすいが、欲求が徐々に変わる・犬が眠くなるといった
  過程は見られない
