# 0032. 眠気は一定の割合で増やし、夜に寝やすいことは寝始める基準で表す

- Status: Accepted
- Date: 2026-09-25

## Context

犬が夜に眠くなるようにしたい（[0024](0024-time-of-day-in-core.md)）。一方で
[0022](0022-offline-catch-up-needs-only.md) により、閉じていた間の欲求は一定の変化率から
一度に計算する。夜だけ眠気の増え方を変えると、この計算と両立しない。

## Decision

- 眠気の増え方は **昼夜を問わず一定** とする
- 夜は、行動意図で Sleep を選ぶ **しきい値を下げる**（例：昼 80、夜 40）ことで、
  夜によく寝る様子を表す

## Consequences

- 見た目は「夜はよく寝る」になり、不在の計算は [0022](0022-offline-catch-up-needs-only.md) のまま
  一定の変化率で済む
- 昼夜の違いは行動意図の決め方（`behavior`）だけに現れ、欲求の計算（`needs`）は時刻を知らずに済む

## Alternatives considered

- **夜は眠気の変化率を上げる**: 数値の上でも夜に眠くなるが、不在の計算で昼と夜の区間を分けて
  足し合わせる必要があり、[0022](0022-offline-catch-up-needs-only.md) の変更が要る
