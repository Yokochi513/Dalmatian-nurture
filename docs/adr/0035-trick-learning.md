# 0035. 芸は習熟度で覚え、上がり幅は機嫌となつき度で決め、乱数は使わない

- Status: Accepted
- Date: 2026-09-25

## Context

[0008](0008-time-progression-hybrid.md) により、芸は世話の積み重ねで覚える。
[0034](0034-tricks-unlocked-by-stage.md) で芸の一覧を決めたが、練習と披露の仕組みは決まっていない。

## Decision

- 犬のメニューの **「しつける」** で練習する芸を選び、芸ごとの **習熟度（0〜100）** が上がる
- 上がり幅は **基本値 × 機嫌となつき度による係数** とし、**乱数は使わない**
- 習熟度が100になると習得し、出来事 LearnedTrick を返す（[0020](0020-core-state-read-events-returned.md)）
- 習得した芸は犬のメニューの **「芸をさせる」** で披露でき、なつき度が少し上がる

```
しつける → [おすわり 60/100] [お手 20/100]
  習熟度 += 基本値 × 機嫌となつき度の係数
  100 で習得（出来事 LearnedTrick）
芸をさせる → [おすわり] → 披露、なつき度 +少
```

## Consequences

- 機嫌となつき度を保つことが、芸を早く覚えることにつながる
- 乱数がないため、同じ操作で必ず同じ結果になり、単体テストで結果が決まる
- 「芸をさせる」が世話の一覧に加わる。クールダウンや1日の上限の対象にするかはバランス調整で決める
- 失敗する・よそ見をするといった犬らしい揺らぎは表現できない

## Alternatives considered

- **練習が確率で成功する**: 犬らしさは増すが、乱数を外から注入してテストで固定する仕組みと、
  失敗時の演出が必要になる
- **回数だけで覚える**: 最も単純だが、機嫌やなつき度が芸に関係しなくなる
