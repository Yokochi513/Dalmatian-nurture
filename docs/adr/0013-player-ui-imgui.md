# 0013. プレイヤー向けUIも Dear ImGui で描く

- Status: Accepted
- Date: 2026-09-25

## Context

[0012](0012-first-person-controls.md) により、世話のメニュー・照準・欲求のゲージ・
初回の名前入力（[0011](0011-scenes-home-and-walk.md)）といったプレイヤー向けUIが必要になった。
[0006](0006-dependency-libraries.md) では Dear ImGui をデバッグUI用として導入しているが、
プレイヤー向けUIの描き方は決まっていない。UIには日本語の表示と入力が必要である。

## Decision

プレイヤー向けUIも **Dear ImGui** で描く。

- デバッグUIとは別のスタイル（枠なし・独自の配色・フォント）を用意し、描画時に切り替える
- 日本語は ImGui のフォント読み込み機能で日本語フォントを読み込んで表示する

## Consequences

- 依存ライブラリを追加せずに済み、日本語の表示と入力（名前入力）も ImGui の機能で賄える
- 凝った見た目のUIには向かず、シンプルな見た目になる
- UIの描画を自作しないため、UIはポートフォリオで示す技術の対象外になる
- 日本語フォントのファイルを同梱する必要があり、再配布できるライセンスのフォントを選ぶ
  （[0007](0007-asset-pipeline-gltf-blender.md) と同様にライセンスを記録する）
- 日本語の文字をすべて読み込むとフォント画像が大きくなるため、読み込む文字の範囲を絞る

## Alternatives considered

- **UIの描画を自作する**: 見た目の自由度が高く示せる技術も増えるが、フォントの読み込み
  （stb_truetype の追加）と日本語の文字画像の管理が必要になり、工数が大きい
- **最初は ImGui で作り、後で自作に差し替える**: 差し替えに備えてUIの記述と描画を分離する
  必要があり、差し替えまでの二重の手間が発生する
