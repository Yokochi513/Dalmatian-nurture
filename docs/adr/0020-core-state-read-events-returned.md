# 0020. app は core の状態を毎フレーム読み取り、一度きりの出来事は戻り値で受け取る

- Status: Accepted
- Date: 2026-09-25

## Context

`app` が `core` から受け取る情報には2種類ある。

- 欲求・行動意図・成長段階のように、毎フレーム表示に使う **状態**
- 「成長した」「芸を覚えた」のように、一度だけ演出する **出来事**

これらを `core` から `app` へどう渡すかを決める必要がある。

## Decision

- **状態** は、`app` が毎フレーム `core` から読み取る
- **出来事** は、`core` を1ステップ進める関数や世話の関数の **戻り値のリスト** として返す

```cpp
auto events = sim.step(now);      // {Grew, LearnedTrick, ...}
auto events = sim.do_care(Feed);  // {Accepted, ...}
const DogState& s = sim.state();  // 毎フレーム読む
```

（関数名は例であり、実際の名前は実装時に決める）

## Consequences

- 出来事がいつ起きたかが呼び出しの流れから明らかで、追いやすい
- `core` の単体テストは、戻り値と状態を確かめるだけで済む
- 出来事を受け取った `app` は、その場で処理するか保持する必要がある。戻り値を捨てると
  出来事が失われる
- 閉じていた間の経過を起動時にまとめて進めた場合も、その間の出来事を戻り値として受け取り、
  「おかえり」の表示（[0011](0011-scenes-home-and-walk.md)）に使える

## Alternatives considered

- **すべて状態を読み取るだけにする**: `core` は最も単純だが、変化の検出が `app` の
  あちこちに散らばり、漏れやすい
- **出来事をコールバックで通知する**: 受け手を増やしやすいが、どの順番で何が呼ばれるかが
  追いにくく、登録した関数の寿命の管理も必要になる
